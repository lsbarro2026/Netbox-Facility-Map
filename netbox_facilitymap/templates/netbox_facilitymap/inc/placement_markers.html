{% comment %} Rack/device placement markers, included by floor_rooms.html. Expects `markers` (from previews.placement_markers): a pre-computed transform, a `glyph` list of styled SVG primitives (the device's schematic shape from DeviceShapes — an AP's broadcast puck, a switch's port row, …), a label, and a permission-scoped `url` to the rack/device's NetBox page (empty when it didn't resolve). When `m.url` is set the marker links to that page (mirroring how room polygons wrap on `s.url` in floor_rooms.html); otherwise it's link-less. Each primitive carries its own inline `style` (the host page loads no plugin CSS) and a non-scaling stroke so the glyph reads at a stable weight however the embed SVG is scaled. {% endcomment %} {% for m in markers %} {% if m.url %}{% endif %} {% for g in m.glyph %} {% if g.tag == 'rect' %} {% elif g.tag == 'line' %} {% elif g.tag == 'circle' %} {% elif g.tag == 'path' %} {% endif %} {% endfor %} {% if m.label %} {{ m.label }} {% endif %} {% if m.url %}{% endif %} {% endfor %}
