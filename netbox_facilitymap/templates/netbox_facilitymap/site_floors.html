{% comment %} Facility-map floor picker injected on a Site's detail page. Mirrors the SPA building view (App.renderBuilding): a grid of floor cards, one per rendered floor of the building(s) whose `siteSlug` matches this Site's slug. Each card links to that floor's NetBox Location page. Self-contained: presentation is inline so it needs none of the plugin stylesheet, which isn't loaded on dcim pages. Because it renders INSIDE a NetBox page it does inherit NetBox's Tabler palette, so every surface/text colour below is a theme-aware `--tblr-*` var (hex fallback kept in case the var is ever absent) and the panel follows NetBox's light/dark mode for free. The one exception is the thumbnail's `#fff` backing — see its note below. {% endcomment %}
